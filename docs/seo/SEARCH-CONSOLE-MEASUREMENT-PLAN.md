# AionSi SEO Measurement Plan

## Objective

Turn the existing technical SEO, capability, evidence and strategic-account layers into a measurable organic-demand system.

## Measurement funnel

Search query → landing page → capability → engineering evidence → target account → contact / engineering requirement

## Search Console setup

1. Verify `aionsi.com` in Google Search Console using the Google-provided verification method.
2. Submit the canonical sitemap at `/sitemap.xml`.
3. Confirm `robots.txt` exposes the sitemap.
4. Record the verification date and Search Console property owner internally.
5. Re-submit the sitemap after major route-family changes.

The repository must not contain a guessed or fabricated verification token. Use only the exact token or verification file provided by Google Search Console.

## Weekly SEO scorecard

Track:

| Metric | Purpose |
|---|---|
| Impressions | Search visibility growth |
| Clicks | Organic traffic growth |
| CTR | SERP relevance / title quality |
| Average position | Ranking movement |
| Landing pages | Which pages attract discovery |
| Queries | What the market is actually searching for |
| Target-account pages | Strategic-account discovery |
| Evidence-page engagement | Technical intent |
| Engineering enquiries | Commercial outcome |

## Opportunity rules

### High impressions + low CTR
Rewrite title, meta description and search-intent framing.

### High impressions + position 8–20
Improve depth, internal linking and evidence coverage before creating a new page.

### High clicks + low enquiry conversion
Strengthen evidence, qualification path and CTA.

### Account-page impressions
Expand the specific account page only after query data confirms demand.

### Technical-page impressions
Create adjacent content around the same engineering topic and link back to the authoritative evidence page.

## Account-based SEO

Prioritize account-specific content only where the capability and evidence are supported.

Example path:

AMD → Physical Design → profile-derived engineering evidence → capability relevance → engineering discovery

Ayar Labs → optical/chiplet engineering → technical evidence → capability relevance → engineering discovery

Synopsys → verification / implementation → technical evidence → ecosystem relevance → engineering discovery

## Reporting cadence

### Weekly

Review search queries, landing pages, CTR and ranking movements.

### Monthly

Review organic contribution to engineering enquiries and strategic-account discovery.

### Quarterly

Re-score target accounts and content priorities based on search visibility, engagement and commercial conversion.

## Governance

No customer relationship, project ownership, performance metric or technical result should be added to SEO content unless the source is approved for external publication.

Profile-derived evidence must remain labelled as representative engineering experience and must not imply customer attribution.
